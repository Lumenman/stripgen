# Заметки

## Аудит кода, 2026-10-14/15

Сторонний аудит (`AUDIT.md`, удалён) сверили с кодом и проверили запуском. Короткий итог:

**Исправлено:**
- Декодер: имена, которые отличаются только регистром (`AAA.txt` и `aaa.txt`), раньше падали посреди записи
  на Windows и macOS. Теперь это ошибка до записи.
- CLI: `OSError` (нет входного файла, нет папки для `-o`) выводится как `error: ...`, а не traceback.
- Кодер: имя файла или strip id не в ASCII даёт понятную ошибку с именем файла; предупреждение, когда id
  обрезается до 6 символов (`PROGRAM1` и `PROGRAM2` дают один id `PROGRA`).
- `--text`: не добавляет второй `$1A`, если файл уже кончается на него.
- `robust_line`: `RankWarning` от `np.polyfit` на мусорных кропах больше не попадает в stderr.
- Тест: пишет `skipped`, если сэмпла Distripitor нет; `run_corpus.py` считает оригиналы, а не берёт `7`.

**Отклонено, с причиной:**
- «`TypeError`/`LinAlgError` в `read()`»: на 300 мусорных изображениях `read()` бросил только `ValueError`;
  `keep` в `robust_line` не может опустеть (точки не дальше медианы всегда проходят порог `3*median`).
- «`.txt` даёт id из пробелов»: `splitext('.txt')` = `('.txt', '')`, id будет `.TXT`.
- «Коллизия id портит данные»: декодер предупреждает о разных полосах с одним id и номером и берёт первую.
- Порог Otsu после поворота: порог по исходному изображению правильнее, белая кайма сдвинула бы его.
- `-o out.png` → `out.png-1.png`: `-o` по справке задаёт префикс имени.
- Единый `SoftstripError`, `errors.py` с кодами, стриминг рендера, свой рендерер ESC/P для `fx80_render.py`:
  нет требований, под которые они нужны.
